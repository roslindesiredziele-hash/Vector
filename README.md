Overview
A modular C++ project implementing a custom dynamic vector class with object‑oriented design, memory management, and unit tests. Demonstrates core data‑structure concepts through clean architecture and practical examples.

Features
Custom dynamic vector implementation

Safe memory management

Copy/move semantics

Operator overloading

Unit tests

Project Structure
src/ — vector implementation

tests/ — unit tests

Vector.vcxproj — Visual Studio project

Build & Run
Open the .vcxproj in Visual Studio and build the solution.

Tests
Run the test executable or use Visual Studio’s test runner.
